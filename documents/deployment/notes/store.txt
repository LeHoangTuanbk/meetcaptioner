# Chrome Web Store Description

## Short Summary (from manifest)
Capture and translate browser meeting captions in real-time

## Full Description (copy below for store listing)

---

Never miss a word in your browser meetings again.

MeetCaptioner captures live captions and translates them instantly using AI — perfect for international meetings, language learners, or anyone who needs accurate meeting notes.

🎯 KEY FEATURES

• Real-time Caption Capture — Automatically captures every word spoken in supported browser meetings with speaker identification
• AI-Powered Translation — Translate to 19+ languages using OpenAI, Anthropic, or Ollama (local/cloud)
• Floating Overlay — Draggable, resizable panel that stays out of your way
• Meeting History — All your captions are auto-saved locally for later review
• Export Options — Download captions and translations as text files
• Editable Translations — Click to edit any translation manually
• Smart Fallback — Automatic model switching when rate limits hit
• Privacy First — All data stored locally on your device, never sent to external servers

🌍 SUPPORTED LANGUAGES

Vietnamese, English, Persian, Chinese, Japanese, Korean, Spanish, French, German, Portuguese, Russian, Arabic, Hindi, Italian, Thai, Indonesian, Dutch, Polish, Turkish

🤖 AI PROVIDERS

Choose your preferred AI provider:
• OpenAI (GPT-4.1 Mini, GPT-4.1, GPT-5 Nano, GPT-5.1, GPT-5.2, GPT-5 Mini)
• Anthropic (Claude Haiku 4.5, Claude Sonnet 4.5, Claude Opus 4.5)
• Ollama (Local LLM or Ollama Cloud) — Run models like Qwen, Llama, Gemma locally for free

💡 PERFECT FOR

• International teams with multilingual meetings
• Language learners practicing comprehension
• Accessibility — read along with spoken content
• Meeting documentation and note-taking
• Anyone working across language barriers

🔒 PRIVACY & SECURITY

Your API keys and meeting data stay on your device. We don't collect, store, or transmit any personal information. Translations are processed directly through your own API accounts.

📋 HOW TO USE

1. Install the extension
2. Join a supported browser meeting
3. Enable native captions or live transcription in the meeting platform
4. Configure your API key in Settings
5. Toggle translation ON in the overlay
6. Watch real-time translations appear!

SUPPORTED MEETING PLATFORMS

• Google Meet
• Microsoft Teams Web
• Zoom Web App

Note: Native desktop Zoom and native desktop Teams apps are not supported.

## Privacy & Permissions (for Chrome Web Store form)

### Single Purpose Description
```
MeetCaptioner captures and displays real-time captions from supported browser meetings with AI-powered translation. It provides a floating overlay showing original captions alongside translations, helping users understand multilingual conversations and save meeting transcripts. Users can choose from cloud AI providers (OpenAI, Anthropic) or run local LLMs via Ollama for privacy-focused translation.
```

### Storage Permission Justification
```
The storage permission is required to:
1. Save user preferences (API provider, model selection, target language)
2. Store API keys locally for translation services
3. Auto-save meeting captions and translations for later review in Meeting History
4. Preserve custom translation prompts configured by the user
All data is stored locally on the user's device and never transmitted to external servers.
```

### Host Permission Justification
1. meet.google.com - Inject content script to capture live captions, read speaker names and timestamps, and render the translation overlay on Google Meet.

2. teams.microsoft.com / teams.live.com - Inject content script to detect supported Teams Web meeting surfaces, capture visible caption text, and render the translation overlay.

3. *.zoom.us - Inject content script into supported Zoom Web App meeting surfaces, capture visible subtitle text, and render the translation overlay.

4. api.anthropic.com & api.openai.com - Send caption text for AI translation using user's own API key. No data sent without user configuration.

5. localhost/127.0.0.1 - Support local Ollama LLM for privacy-focused translation without external servers.

6. ollama.com - Support Ollama Cloud service for users preferring hosted option.

All API keys stored locally. Users choose their provider and must configure before any data is sent.
